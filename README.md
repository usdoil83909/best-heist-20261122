Entry for the make.fun bounty [Make the best heist game](https://make.fun/bounty/best-heist-game-20261122-0559).

Nightlift is an original 2D top-down stealth heist game built with the HTML5 canvas and plain ES modules — no engine, no build step. Guide the thief across the vault floor, read the guards' sweeping vision cones, slip between the cameras' shadows, grab the loot and reach the getaway van before the alarm meter fills.

- Play: `node serve.ts` then open http://localhost:8080 — or any static server pointed at `game/`.
- Keyboard and mouse. All art, sound and names are original.
